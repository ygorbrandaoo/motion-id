# Data

Download the original [UCI HAR archive](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones) and extract it into `data/raw/UCI HAR Dataset/`.

Keep the original files unchanged. Raw data, processed data, and the downloaded archive are local files excluded from Git. The repository does not require a dataset download to read the research proposal.

See [dataset documentation](../docs/dataset.md) for the expected files.
